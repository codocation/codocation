## What is Codocation?

Codocation is a docs-as-code authoring tool. Your documentation is plain files in Git: pages are written in
Markdown, and navigation and configuration are defined in YAML. Codocation adds a live preview, a
visual navigation tree, and validation that catches broken pages before they are published. The project builds into a static site or a PDF, or deploys to GitHub
Pages or Cloudflare Pages in one click. Codocation runs as a JetBrains IDE plugin or a standalone app, and both open the
same project.
